Bluetooth tethering via browser

Browsers cannot create Bluetooth PAN or advertise as a Bluetooth hotspot. Use OS tethering instead:

  • Android: Settings → Network & Internet → Hotspot & tethering → enable Bluetooth tethering (or Wi‑Fi hotspot).
  • iOS/iPadOS: Settings → Personal Hotspot → allow others to join (Wi‑Fi/USB only; Bluetooth PAN not available to browsers).
  • Windows/macOS: Share internet via Mobile Hotspot (Wi‑Fi) or Bluetooth PAN from system settings.
